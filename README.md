## 软蒸馏：
**对比传统蒸馏**
   “传统模型蒸馏”(Model Distillation)是⼀种知识迁移方法，通过将高性能大型模型（教师模型）的决策逻辑与知识分布传递至轻量化小型模型（学生模型），来大幅压缩模型规模与计算开销。（于2014年年底的NIPS会议提出*信息来源于维基百科）
   “软（模型）蒸馏”（Soft Model Distillation）是一种项目操作方法，通过让高性能大型模型（领导组织者）指定项目计划，撰写项目思路；中型模型（代码撰写者）撰写代码；小型模型（底层打工者）运行代码和测试，来大幅降低开发成本和算力消耗。（于2026年8月16日由白小谦提出）
